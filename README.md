## Quick start by stack

**Python (Windows / macOS / Linux)**
```bash
pip install numpy matplotlib mysql-connector-python
python projects/disease-simulation/diseaseSim.py
python projects/data-structures/DSA_Assignment.py
```

**C / Unix (Linux or WSL)**
```bash
sudo apt install -y build-essential   # once
cd projects/unix-prime-checker && make && ./prime numbers.txt
cd ../snake-treasure-game && make && ./treasure map.txt
```

**MySQL + Python** — see [film-festival-database README](./projects/film-festival-database/) (`DB_PASSWORD` required).
