# HelpEra

**Course:** Human–Computer Interaction / UI-UX  
**Team:** UXplorers  
**Year:** 2025–2026

HelpEra is a UI/UX group project — an app concept designed in **Figma**, supported by research reports, advertising materials, and a high-fidelity walkthrough.

**Tech:** Figma · UI/UX · HCI

## Environment / how to view

No code to compile. Open this folder in VS Code or File Explorer.

- **Figma** — use the prototype links below (browser)
- **PDFs / PPTX / DOCX** — open with your usual apps
- **Walkthrough video** — play the `.mp4` locally
