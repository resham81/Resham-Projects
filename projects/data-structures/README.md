# Data Structures Assignment

**Course:** Data Structures & Algorithms (DSA)  
**Year:** 2025  
**Author:** Resham Furqan

Interactive menu app for an autonomous vehicle management system — custom deque, graphs, heapsort/quicksort, and vehicle operations.

**Tech:** Python (standard library only)

## Environment

- **OS:** Windows, macOS, or Linux
- **Python:** 3.10+ recommended
- No extra packages required

## Run

```bash
cd projects/data-structures
python DSA_Assignment.py
```

Use the on-screen menu (options 1–18). Choose **18** to exit.

### Quick smoke test

1. Add Location → e.g. `A`, then `B`
2. Add Road between `A` and `B`
3. Display Road Network
4. Exit
